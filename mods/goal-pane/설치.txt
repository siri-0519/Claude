목표 패널 모드를 내 컴퓨터의 로컬 세션에서 켜는 법 (윈도우와 맥이 같다)

이 모드는 두 가지를 보여 준다. 낱말은 업계에서 통용되는 말을 먼저 골랐다: 의도(intent) · 가정(assumption) · 확인 질문(clarifying question).
- 목표: 사용자의 요청들이 궁극적으로 이루려는 것. 20자 안팎으로 짧고, 거의 바뀌지 않는다. 세션 제목 맨 뒤 대괄호 안에 표시된다.
- 의도: AI 에이전트가 사용자의 최근 요청을 어떻게 이해했는가. 메시지마다 바뀐다. 입력창 바로 위 영역에 보인다. AI 에이전트가 사용자가 말하지 않은 것을 전제하거나 대신 고른 것이 있으면 「가정」(노랑), 물어야 할 것이 있으면 「확인 질문」도 함께 보인다. 없으면 그 줄은 생략된다.
  가정 줄마다 오른쪽 끝에 ✓ ✗가 있다. ✓를 누르면 그 가정이 초록 「확정」으로, ✗를 누르면 빨간 취소선 「틀림」으로 바뀐다. 한 가정에는 둘 중 하나만 선택되고, 같은 것을 한 번 더 누르면 풀린다. 확정한 가정은 AI가 다시 묻지 않고 그대로 진행한다. 표시한 가정은 바로 보내지 않고, 사용자가 다음 메시지를 보낼 때 함께 AI 에이전트에게 전달된다(기록 파일에도 저장된다). 가정이 여럿이어도 다 고른 뒤 한 번에 전달하려는 것이다.
입력창 위 영역과 패널은 보여 주기용이라 이것만 보인다. 왜 그렇게 이해했는지(근거가 된 사용자의 말 · 그렇게 이해한 까닭)와 목표가 바뀐 까닭은 화면에 내지 않고, 세션마다 파일 하나에 따로 쌓는다: 내 사용자 폴더의 .claude/goal-pane/기록/<세션 id>.jsonl
채팅 옆 패널은 채팅 칸을 좁히므로 저절로 열지 않고, /goal-pane 을 입력할 때만 연다. 패널에는 지금 의도와 지난 의도가 있다. 목표는 세션 제목에만 있고 입력창 위 영역 · 카드 · 패널 어디에도 보이지 않는다.

세션 제목 규칙: 대괄호 앞은 사용자가 바꾸고, 맨 뒤 대괄호는 제목 훅이 바꾼다. 예) 「모드 설치 및 설정 [AI가 사용자 의도를 정확히 이해하게]」
- 목표가 바뀌면 다음 메시지를 보낼 때 「[바뀜]」이 추가되고, 그다음 메시지에서 지워진다. 예) 「모드 설치 및 설정 [바뀜] [새 목표]」
- 제목은 메시지를 보낼 때만 바뀌므로, 목표가 정해진 그다음 메시지부터 표시된다.
- 사용자가 맨 뒤 대괄호를 직접 고치면 그것도 사용자 것으로 두고, 훅은 그 뒤에 새 대괄호를 추가한다.
- 제목은 모드가 아니라 설정 훅(이 폴더의 title-hook.mjs)이 바꾼다. 데스크톱 앱에서는 모드의 제목 훅이 다른 플러그인(cc-plugin-sec-default)에 막혀 돌지 않는 것을 확인했다(2026-11-12). 켜는 법은 3-2.
클라우드 세션과 웹에서는 패널이 그려지지 않는 것을 확인했다. 데스크톱 앱의 로컬 세션에서는 옆 패널과 입력창 위 영역이 그려지는 것을 확인했다(2026-11-12).

1. 이 레포(Claude)를 내 컴퓨터에 받는다.
2. 내 사용자 폴더의 .claude/settings.json 파일을 연다. 윈도우에서는 C:\Users\<사용자 이름>\.claude\settings.json 이고, 맥에서는 ~/.claude/settings.json 이다. 파일이 없으면 만든다.
3. 그 파일에 아래 칸을 더한다. 경로는 이 폴더(mods/goal-pane)가 내 컴퓨터에 있는 실제 위치로 바꾼다. 윈도우에서도 경로의 구분자는 / 로 적는다.

   "env": { "CLAUDE_CODE_PLUGIN_DIRS": "C:/Users/<사용자 이름>/work/Claude/mods/goal-pane" }

   파일에 이미 "env" 칸이 있으면, 그 안에 "CLAUDE_CODE_PLUGIN_DIRS" 줄 하나만 더한다.
3-2. 세션 제목에 목표를 표시하려면, 같은 파일의 "hooks" 칸에 아래를 더한다. node 가 깔려 있어야 한다. 경로는 3과 같이 바꾼다.

   "UserPromptSubmit": [ { "hooks": [ { "type": "command", "command": "node \"C:/Users/<사용자 이름>/work/Claude/mods/goal-pane/title-hook.mjs\"", "timeout": 10 } ] } ]

   이미 "UserPromptSubmit" 이 있으면 그 안의 "hooks" 목록에 { "type": "command", … } 하나만 더한다. 이 훅은 무슨 일이 있어도 메시지를 막지 않는다.
4. 데스크톱 앱을 완전히 껐다 켜고, 로컬 세션을 새로 연다.
5. 메시지를 하나 보낸다. AI 에이전트가 적은 결과에 「연결된 화면: desktop」이 나오고 입력창 위 영역에 이해한 의도가 표시되면 된 것이다. 그다음 메시지부터 세션 제목 뒤에 [목표]가 표시된다.
   /goal-pane 을 입력하면 옆 패널이 열리고, 패널이 그려졌는지, 아니면 왜 그려지지 않았는지를 알려 준다.

모드를 끄려면 3에서 더한 줄과 3-2에서 더한 훅을 지우고 데스크톱 앱을 다시 켠다.
