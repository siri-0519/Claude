# 틀

문서 레포의 틀이다. 복사해서 이름을 바꾸고 `.ops.yml` 을 고쳐 쓴다. 서브모듈로 잇지 않는다.
설계는 `설계.md`, 기계 규칙은 `ops/rules/기계.yml`, 판단 규칙은 `ops/rules/판단.md` 에 있다.

이 파일은 `ops build` 가 만든다. 소개는 `.ops.yml` 의 소개 칸, 아래 줄은 주제 파일마다의 「지금」 절 첫 줄이다.

| 파일 | 지금 |
|---|---|
| `설계-부록.md` | 부록 B의 문장이 레포마다 판정 모델에 넘기는 전문이다. 옮길 때 그 레포의 `ops/rules/판단.md`에 그대로 적는다 [확인 2026-09-14]. |
| `설계.md` | 이 레포는 틀이다. 복사해서 이름을 바꿔 쓰고 서브모듈로 잇지 않는다 [확인 2026-09-14]. |

규칙은 `ops/rules/`, 설계는 `설계.md`, 어긋난 파생물은 `memory/어긋남.md` 에 있다.
